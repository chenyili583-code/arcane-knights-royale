## 📖 專題簡介 (Project Overview)
《奧術榮耀：中世紀暗黑哥特大逃殺》是一款融合**中世紀暗黑哥特奇幻 (Dark Gothic Fantasy)** 與**現代大逃殺 (Battle Royale)** 機制的 2D 即時戰鬥網頁遊戲。  
玩家與 15 位各具風格的 AI 魔法騎士一同降落於遠古黑石遺跡。在不斷收縮的「蝕魔風暴」逼近、遠古遺跡巨像甦醒、血色沼澤與雷霆符文陷阱密布的戰場中，善用死靈召喚、暗影瞬移、專屬天賦加點、雙向傳送門與草叢伏擊，奪取「永夜聖殿大導師」的最終冠冕！

## 🎮 操作控制說明 (Controls)
- **移動 (Move)**：`W` `A` `S` `D` 或 `方向鍵`
- **騎士斬擊 (Melee Slash)**：滑鼠瞄準 + `滑鼠左鍵點擊`（具備 16% 暴擊機率）
- **主核心法術 (Primary Spell)**：滑鼠瞄準 + `滑鼠右鍵點擊`（烈焰 / 冰柱 / 劍氣 / 連鎖電 / **鮮血詛咒** / **神聖天罰**）
- **奧術絕技 (Special Arcane Ability)**：`E` 鍵（霜凍新星 / 聖光壁壘 / 烈火之環 / 狂暴加速 / **死靈復甦** / **暗影瞬移**）
- **奧術衝刺 (Dash)**：`空白鍵 (Space)`（快速衝刺並獲得短暫無敵位移）
- **生命聖水 (Heal Potion)**：`Q` 鍵（即時回復 350 點生命值）
- **📱 虛擬搖桿支援**：點擊頂部「📱 虛擬按鍵」按鈕，即可在手機、平板或觸控螢幕上以左虛擬搖桿與右技能輪盤暢玩！

## 🩸 四大被動天賦樹 (工坊自由配置)
1. **吸血鬼之吻 (Vampiric Touch)**：造成傷害的 15% 即時轉化為自身生命回復。
2. **哥特死戰 (Gothic Fortitude)**：當生命低於 30% 時，激發狂戰本能，獲得 40% 傷害減免。
3. **暗影疾風 (Shadow Swiftness)**：衝刺冷卻時間由 3.5s 縮減為 2.5s，且衝刺後 2 秒內移速提升 25%。
4. **奧術湧流 (Arcane Surge)**：每次擊敗敵人立即回復 50 點法力值並減少所有技能冷卻 2 秒。

## 🛠️ 改善紀錄 (Changes Log - 期末簡報必填 3 項)
本專題依據課程規範，在 AI 迭代開發中具備 3 項以上明確改善紀錄：

1. **改善紀錄一：大逃殺毒圈收縮演算法與受傷節奏優化**
   - **原本的問題**：最初毒圈以固定等速收縮，玩家經常在一開始就因地圖過大找不著敵人，而在最後階段毒圈又收得太慢缺乏緊張感。
   - **怎麼改與原因**：改採四階段動態收縮機制（初階緩衝 15s 縮半徑至 750 -> 中階 12s 縮至 450 -> 高階 10s 縮至 200 -> 終局決戰 8s 縮至 30），並隨階段提升每秒侵蝕傷害（18 -> 34 -> 58 -> 95 DPS），同時加入 5 秒警報號角與金色虛線預告圈。
   - **如何驗證**：實測每局戰鬥節奏精準收斂在 3～4 分鐘，AI 騎士在毒圈逼近時會優先執行逃生邏輯，最後圈成功誘發緊張決戰。

2. **改善紀錄二：管理／資料功能 (CRUD) 與遊戲實戰無縫即時聯動及 JSON 備份**
   - **原本的問題**：最初騎士工坊的數值調整僅儲存於靜態表單，進入戰局時仍使用寫死的預設騎士數值，未符合「前台畫面即時連動更新」之加分要點。
   - **怎麼改與原因**：重新設計 `StorageManager` 狀態匯流排，在騎士工坊新增或編輯騎士屬性（HP, MP, ATK, SPD）、技能組合與全新被動天賦（吸血/死戰/疾風/湧流）後，大廳立即同步更換外觀與數值條，戰局初始化直接讀取玩家自訂角色的傷害倍率與技能冷卻，並新增 **JSON 戰報資料匯出與匯入功能** 及 **六大傳奇成就系統**。
   - **如何驗證**：建立自訂「冥淵死靈使者」，配置鮮血詛咒、死靈復甦與吸血天賦，進入遊戲實戰確認攻擊帶有吸血綠字浮動動畫，召喚僕從正常攻擊敵人，並成功匯出戰報 JSON 檔案。

3. **改善紀錄三：零外部依賴之 Web Audio API 程序化音效合成與哥特氛圍 BGM**
   - **原本的問題**：早期採用外部 `.mp3` 音檔播放揮劍與法術音效，但受限於靜態託管跨域與瀏覽器自動播放政策，經常發生音檔遺失、載入延遲 (404 / 403) 與聲音卡頓。
   - **怎麼改與原因**：全面替換為 HTML5 原生 `Web Audio API`，透過振盪器 (Oscillator)、白噪音緩衝 (BufferNoise) 與濾波器 (BiquadFilter) 即時合成 19 種戰鬥音效（揮劍風切、火球爆炸、冰柱晶鳴、連鎖電流、暗影瞬移、神聖天罰、巨像咆哮、暴擊打擊金屬音等），並研發純程序化 **哥特暗黑氛圍 BGM 合成引擎**（大教堂風琴低音無伴奏和弦 + D小調鐘鳴）。
   - **如何驗證**：在完全無連網或新開無痕瀏覽器下點擊開始戰鬥，揮劍與釋放法術時皆能即時傳出打擊音效，背景流暢響起幽暗莊嚴的哥特音樂，延遲低於 10ms 且完全零網路請求。

## 🚀 部署至 Vercel 教戰守則 (Deploy to Vercel)
1. 在 GitHub 上建立一個新的公開專案庫（例如 `arcane-knights-royale`）。
2. 將本專案的所有檔案推送到 GitHub：
   ```bash
   git init
   git add .
   git commit -m "feat: Gothic Royale overhaul with World Boss, Talents, Procedural Gothic BGM, Touch Controls and JSON CRUD"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/arcane-knights-royale.git
   git push -u origin main
   ```
3. 登入 [Vercel](https://vercel.com/)，點擊「Add New...」->「Project」。
4. 選擇剛才建立的 GitHub 專案庫，Framework Preset 選擇 `Other` 或保持預設，點擊「Deploy」。
5. 部署完成後將獲得專屬公開網址（例如 `https://arcane-knights-royale.vercel.app`），即可填入期末專題草稿中！
